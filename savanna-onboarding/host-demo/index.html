Host demo: the platform receives the data

This page plays the part of the platform (Savanna, or any site). It adds the module with two script tags and SavannaOnboarding.mount(), listens for every event, and saves each one as a record.

Demo, for developers and judges. Records are saved only in this browser (IndexedDB). Nothing is sent anywhere unless you turn on "Send to your endpoint" below.

    3. Send to your endpoint (optional, off by default)
    
      
    The first step towards a "bring your own backend" adapter: each new record is sent with
        POST as JSON to an address you choose. The module itself still sends nothing; this page (the host) does.
    
      
    
        
    
          
          For example https://example.org/savanna/events. It must accept cross-site requests (CORS).
          
          
        
    
        
    
      
    
      
    Only use an endpoint you control. Records include the learner's answers, and Support Passport
        answers are private: a real platform must have the learner's consent before storing or sharing them.
